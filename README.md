# 🧵 Threads Clone - Fullstack Social Network

Một ứng dụng mạng xã hội thu nhỏ được lấy cảm hứng từ Threads (Meta), cho phép người dùng kết nối, chia sẻ suy nghĩ và tương tác với nhau trong thời gian thực.

## 🚀 Tính năng chính

Dự án mô phỏng đầy đủ các luồng hoạt động chính của một mạng xã hội hiện đại:

- **🔐 Xác thực người dùng:** Hệ thống Đăng ký, Đăng nhập và Đăng xuất bảo mật.
- **📝 Đăng tải Threads:** Cho phép người dùng chia sẻ suy nghĩ thông qua các bài viết văn bản (Text-based posts).
- **❤️ Tương tác thời gian thực:** \* Like và bỏ Like bài viết.
    - Trả lời (Reply) để tạo các cuộc hội thoại trong từng bài viết.
- **👥 Hệ thống Follow:** Theo dõi hoặc bỏ theo dõi người dùng khác để cập nhật bảng tin.
- **👤 Trang cá nhân (Profile):** Hiển thị thông tin cá nhân, danh sách bài viết và người theo dõi.
- **🌓 Chế độ hiển thị:** Hỗ trợ giao diện Sáng/Tối (Light/Dark Mode) cực mượt.
- **🔍 Tìm kiếm:** Tìm kiếm người dùng khác theo tên hoặc username.

| **State Management** | Redux Toolkit          |

## 📦 Cài đặt và Chạy dự án

### 1. Clone dự án

```bash
git clone [https://github.com/ducminh0901/f8-thread-clone.git](https://github.com/ducminh0901/f8-thread-clone.git)
cd f8-thread-clone
```

### 2. Cài đặt thư viện

```bash
npm install
```

### 3. Chạy dự án

```bash
npm run dev

```
